# Security Policy

## Supported Versions

Please make sure the vulnerability is present on the latest or latest beta release before reporting.
If a fix is already applied on the source code but is not in a release, it may have been a coincidence, so please still do report those.

| Version | Supported          |
| ------- | ------------------ |
| Current | :white_check_mark: |
| Beta    | :white_check_mark: |
|< Current| :x:                |

All versions available can still update to the latest release using the in-app updater.

## Reporting a Vulnerability

DM me on Discord! (@kurakanai)
Use this section to tell people how to report a vulnerability. An update will be pushed out asap when a vulnerability is classified as severe. 
Vulnerabilities targeting included NuGet packages don't have an ETA since they rely on the specified NuGet package being updated.
